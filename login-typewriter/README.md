# Login · Typewriter

صفحه ورود با تم ماشین‌تحریر قدیمی. با تایپ در فیلدها، کلیدهای فیزیکی فشار می‌خورند و متن روی کاغذ ظاهر می‌شود.

## فایل‌ها

```
login-typewriter/
├── index.html
├── style.css
├── script.js
└── README.md
```

## اجرا

فایل `index.html` را در مرورگر باز کنید یا با `npx serve login-typewriter` سرو کنید.
