# 🎮 بازی اول ESP32 - نسخه کامل تحت وب

## 📋 توضیحات

این پروژه نسخه کامل و بهبود یافته بازی اول ESP32 است که در یک فایل HTML واحد قرار دارد. بازی شامل تمام ویژگی‌های پیشرفته و یک سیستم راهنمای کامل است.

## ✨ ویژگی‌های جدید

### 🎯 گیم‌پلی بهبود یافته
- **سیستم سطح**: با افزایش امتیاز، سطح بازی بالا می‌رود
- **دشمنان**: از سطح 2 به بعد، دشمنان ظاهر می‌شوند
- **آیتم‌های متنوع**: 4 نوع آیتم با امتیازهای مختلف
- **سیستم قدرت**: قدرت‌های ویژه قابل استفاده

### 🎨 طراحی بصری
- **گرافیک بهتر**: ذرات، انیمیشن‌ها و افکت‌های بصری
- **رنگ‌بندی متنوع**: آیتم‌های رنگی با نمادهای مختلف
- **پس‌زمینه متحرک**: خطوط شبکه و گرادیان‌های زیبا
- **سایه و عمق**: سایه‌ها و حاشیه‌ها برای عمق بصری

### 🎮 کنترل پیشرفته
- **کنترل مداوم**: نگه داشتن کلیدها برای حرکت مداوم
- **کنترل لمسی**: کشیدن انگشت روی صفحه برای موبایل
- **کلیدهای اضافی**: کلید P برای استفاده از قدرت‌ها
- **پشتیبانی کامل موبایل**: ریسپانسیو و بهینه برای موبایل

### 📖 سیستم راهنما
- **دکمه راهنما**: دسترسی آسان به راهنمای کامل
- **باکس popup**: نمایش راهنما بدون تغییر صفحه
- **راهنمای جامع**: توضیح کامل تمام ویژگی‌ها
- **طراحی زیبا**: انیمیشن و طراحی مدرن

### ⚡ سیستم قدرت‌ها
- **سرعت**: افزایش سرعت حرکت برای 5 ثانیه
- **امتیاز**: دریافت 50 امتیاز اضافی
- **محافظت**: محافظت از دشمنان برای 5 ثانیه
- **هزینه**: هر قدرت 100 امتیاز هزینه دارد

## 🎮 نحوه بازی

### کنترل‌ها
- **حرکت**: دکمه‌های جهت‌دار یا WASD
- **جمع‌آوری**: دکمه جمع‌آوری یا Space
- **قدرت**: دکمه قدرت یا کلید P
- **موبایل**: کشیدن انگشت روی صفحه

### اهداف
1. **جمع‌آوری آیتم‌ها**: برای کسب امتیاز
2. **اجتناب از دشمنان**: از سطح 2 به بعد
3. **استفاده از قدرت‌ها**: برای پیشرفت بهتر
4. **رسیدن به سطوح بالاتر**: با کسب امتیاز بیشتر

## 🚀 نحوه اجرا

### روش 1: اجرای مستقیم
```bash
# باز کردن فایل game.html در مرورگر
open game.html
```

### روش 2: سرور محلی
```bash
# با Python
python -m http.server 8000

# با Node.js
npx serve .

# با PHP
php -S localhost:8000
```

### روش 3: سرور آنلاین
- آپلود فایل `game.html` روی GitHub Pages
- استفاده از Netlify یا Vercel
- آپلود روی هر هاست استاتیک
