# 🏎️ بازی ماشین تحت وب

یک بازی ماشین کامل و جذاب که مستقیماً در مرورگر اجرا می‌شود و نیازی به سرور ندارد.

## ویژگی‌ها

- 🚗 **کنترل کامل ماشین**: گاز، ترمز، تغییر لاین
- 🛣️ **سیستم جاده**: 3 لاین با خطوط مشخص
- 🎯 **باکس‌های امتیاز**: جمع‌آوری برای کسب امتیاز
- 🚗 **ماشین‌های دشمن**: چالش و هیجان بیشتر
- 📱 **رابط کاربری زیبا**: طراحی مدرن و ریسپانسیو
- 🎮 **کنترل چندگانه**: دکمه‌ها و کیبورد
- 📊 **نمایش سرعت و امتیاز**: اطلاعات لحظه‌ای
- 🏆 **ذخیره امتیاز بالا**: با localStorage
- 🎮 **صفحه پایان بازی**: نمایش نتایج

## نحوه استفاده

### روش 1: باز کردن مستقیم فایل
1. فایل `index.html` را در مرورگر باز کنید
2. بازی آماده است!

### روش 2: استفاده از سرور محلی (توصیه می‌شود)

#### با Python:
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

#### با Node.js:
```bash
# نصب http-server
npm install -g http-server

# اجرای سرور
http-server
```

#### با PHP:
```bash
php -S localhost:8000
```

### روش 3: استفاده از Live Server (VS Code)
1. افزونه Live Server را در VS Code نصب کنید
2. روی فایل `index.html` راست کلیک کنید
3. "Open with Live Server" را انتخاب کنید

## نحوه بازی

### کنترل‌ها:

#### دکمه‌های روی صفحه:
- **🚗 گاز**: افزایش سرعت ماشین
- **🛑 ترمز**: کاهش سرعت ماشین
- **⬅️ چپ**: تغییر به لاین چپ
- **➡️ راست**: تغییر به لاین راست

#### کنترل با کیبورد:
- `W` یا `↑`: گاز
- `S` یا `↓`: ترمز
- `A` یا `←`: تغییر لاین به چپ
- `D` یا `→`: تغییر لاین به راست

### 🎯 انواع باکس‌های امتیاز:
| نماد | رنگ | امتیاز | توضیحات |
|------|-----|--------|----------|
| + | طلایی | 10 | باکس پایه |
| ★ | قرمز | 20 | باکس باارزش |
| ♦ | بنفش | 15 | باکس متوسط |
| ● | سبز | 25 | باکس نادر |

### 🏆 اهداف بازی:
1. **جمع‌آوری باکس‌ها**: 4 نوع باکس با امتیازهای مختلف
2. **اجتناب از دشمنان**: از 3 ماشین قرمز دوری کنید
3. **کنترل سرعت**: حداکثر سرعت 20 واحد
4. **استفاده از لاین‌ها**: 3 لاین برای حرکت و فرار

### ⚠️ قوانین بازی:
- **برخورد با دشمن**: پایان بازی
- **جمع‌آوری باکس**: کسب امتیاز (10-25 امتیاز)
- **سرعت بالا**: خطر بیشتر اما هیجان بیشتر
- **تغییر لاین**: برای فرار از دشمنان
